01 · How I work

길게 뽑고, 들리는 구간만 잘라 씁니다

VARCO는 소리를 10초 안팎으로 만들어 줍니다. 그런데 소리의 시작과 끝이 안개처럼 흐릿하게 번지고, 쓸 만한 동작음은 그 사이 짧은 구간에 들어 있었습니다. 그래서 길게 생성한 뒤 에디터에서 필요한 구간만 남기는 방식으로 작업했습니다. 파란 영역이 실제로 쓴 부분입니다.

나무 계단 발소리

8.57s 중 0.48s 사용

방문 닫기

2.77s 중 0.65s 사용

입력에 따라 달라진 것

  • 글로만 요청하면 하나의 명료한 소리보다 박자와 패턴이 불규칙한 소리가 자주 나왔습니다.
  • 이미지를 함께 넣으면 요청한 소리 외에 그 장면의 공간음까지 만들어져, 트랙이 여러 개 생겼습니다.
  • 이미지만 넣으면 가장 가까운 소리를 내주지만, VARCO가 익숙한 소리 쪽으로 자꾸 기울었습니다.

생성 후 손본 것

  • 음량: 가장 작은 소리와 큰 소리 차이 38.5dB → 종류별 기준 음량으로 맞춤
  • 경계: 소리 중간에서 시작하거나 끝나는 파일 9개 → 앞뒤 페이드
  • 여백: 문 여는 소리는 실제 0.95s + 무음 3.4s → 쓸 길이로 트리밍
02 · Where I got stuck

시간이 가장 많이 든 네 가지 소리

요청 기록과 생성 파일을 다시 열어, 어디서 시간이 들었고 무엇이 해결의 열쇠였는지 정리했습니다. 회색 상자는 당시 제가 에이전트에게 보낸 요청에서 옮긴 것입니다(오타만 고침).

10.24 06:52 – 10:32요청 19번생성 파일 62개

금속 누름판이 눌리는 소리

  • 저런 퓨처리즘 효과음 내가 원한다고 말하기전까지 빼
  • 너가 생각하는 금속 누름판이 눌리는 소리는 도대체 뭐니?
  • 지금은 그냥 손가락으로 눌러도되는 버튼 소리라서 내가 원하는방향성이랑 달라
무엇이 문제였나

'누름판'이라는 물건 이름만으로는 크기, 무게, 길이가 전해지지 않았습니다. 그 빈칸을 VARCO는 미래적인 기계음이나 손가락 버튼 소리로 채웠고, 저는 발판 크기와 0.5~1초 길이를 뒤늦게 하나씩 덧붙였습니다.

어떻게 풀었나

이틀 뒤 "맨홀 뚜껑이 닫히는 소리 정도"라고 누구나 아는 소리에 빗대자, 9분 만에 쓸 수 있는 소리가 나왔습니다. 물건 이름보다 같은 무게감의 익숙한 소리를 말하는 것이 훨씬 빨랐습니다.

10.14 06:35 – 06:45요청 7번생성 파일 27개

밸브에서 증기가 빠져나오는 소리

  • 기계음 다 빼주고 자연스러운 증기 소리만 남겨줘
  • 매미냐? 왜자꾸 찌르르 거려 푸쉬이이이 소리 구현해달라구..
  • 와 여름인줄 매미소리밖에안남 어떻게해야 너가 이해를 할까
무엇이 문제였나

"기계음을 빼 달라"는 수정을 거듭할수록 소리가 증기에서 멀어져 매미 울음 같은 고음 잡음이 되었습니다. 빼 달라는 말은 무엇을 남길지 알려 주지 못했습니다.

어떻게 풀었나

결국 쓴 소리는 수정 요청 전에, 제가 증기가 '치익' 분출하다 빠르게 잦아드는 모양을 구체적으로 적은 요청에서 나온 후보였습니다. 결과가 멀어지면 수정을 쌓기보다 앞선 후보로 돌아가는 것이 낫다는 걸 배웠습니다.

10.26 05:56 – 06:07요청 5번생성 파일 21개

UI 버튼에 마우스를 올릴 때 나는 짧은 금속음

  • 너무 울리는데 짧고 명료하게
  • 지금도 너무 울려 쇠가 울리는소리를 다 차단해 그냥 녹음실에서 소리 나자마자 막히는 것처럼
무엇이 문제였나

짧은 금속음을 요청해도 쇠가 길게 울리는 소리가 계속 붙었습니다. 여러 번 고쳐 요청하는 동안에도 울림은 줄지 않았습니다.

어떻게 풀었나

최종으로 쓴 소리는 맨 처음 생성한 후보였습니다. 이후로는 첫 후보 세 개를 먼저 충분히 비교하고, 원하는 방향이 보이는 후보를 골라 그것만 다듬는 순서로 바꿨습니다.

10.14 · 10.28요청 11번생성 파일 39개

같은 피아노 음색으로 계이름만 바꾸기

  • 그럼 지금은 도부터 미까지만 가능해?
  • 내가보낸 파일이랑 비교해봤을때 똑같아보여?
  • Please change only the note name to 'Do'.

도레미를 차례로 치는 소리도, 같은 음형에서 계이름만 바꾸는 것도 되지 않았습니다. 피아노 단음 하나로 다시 시도한 결과를 주파수로 재 봤습니다.

요청에이전트가 한 일측정한 음
G5 (784Hz) 피아노 단음효과음 후보 3개F (349.9Hz)
"저 음향으로 도 만들어줘"베리에이션 4개, "도로 변형했다"4개 모두 F4

무엇이 문제였나

베리에이션은 음높이를 옮기지 못하고, 새로 생성하면 음색이 다시 만들어졌습니다. 에이전트는 바꿨다고 답했지만 실제 음은 그대로였습니다.

해결 방향

음색은 VARCO로 한 번만 만들고, 음높이는 Unity AudioSource의 pitch로 옮깁니다. 파에서 위의 도는 +7반음(pitch 1.498), 아래 도는 −5반음(0.749)입니다.

네 사례에서 보인 VARCO의 기본값제 요청 기록에는 "퓨처리즘", "너무 울려", "베이스가 너무 묵직", "지이잉 거리는 전기 소리", "매미"가 반복됩니다. 설명이 비어 있으면 VARCO는 무겁고, 울리고, 기계적인 쪽으로 채웠습니다. 그래서 크기·무게·길이와 공간을 먼저 정해 주는 것이 가장 효과적이었습니다.

03 · Ambience loop

플레이 내내 도는 바람 소리는 효과음으로 조립했습니다

음악 모드로는 어떤 프롬프트를 써도 곡이 전개되어 배경 루프를 만들 수 없었습니다. 효과음 모드로 바람을 여러 번 만들고, VARCO 에디터에서 이어 붙여 1분 루프를 완성했습니다.

  1. 이미지와 함께 요청저택 우풍 소리를 요청하자 트랙 여러 개가 생김
  2. 필요 없는 층 삭제야외 풀벌레 등 요청 안 한 층 정리
  3. 페이드로 이어 붙이기뚝뚝 끊기지 않게 배치
  4. 문제 발견바람 종류가 둘뿐이고 높낮이가 커서 반복이 티 남
  5. 일정한 바람 재생성"처음부터 끝까지 같은 크기" 프롬프트, 후보 3개 모두 사용
  6. 트랙을 나눠 불규칙하게 배치한 트랙에서 겹치면 앞 클립이 잘려서
  7. 60초 → 0초 이음새페이드 대신 바람이 이어지게

이음새 앞뒤 6초 음량 (dB, 0.25초 단위)

이전: 페이드아웃 · 페이드인최종: 바람이 이어지는 방식

이음새의 가장 조용한 순간이 −83dB → −47dB로 올라가, 루프가 돌 때 바람이 꺼지지 않습니다. 마지막 샘플과 첫 샘플도 −0.0155 → −0.0151로 이어져 '틱' 소리가 없습니다.

이음새 확인용 12초

끝 6초 + 처음 6초

6초 지점이 60초 → 0초로 넘어가는 순간입니다.

최종 1분 루프

60s · 반복 재생

루프라는 걸 알리지 않고 다른 사람에게 들려주며 이음새가 들리는지 확인하는 방식으로 검증합니다.

05 · What I'd tell the next creator

다시 만든다면 처음부터 이렇게 요청합니다

  1. 물건 이름 대신, 누구나 아는 비슷한 소리에 빗댄다"금속 누름판"보다 "맨홀 뚜껑이 닫히는 소리"가 9분 만에 통했습니다.
  2. 크기 · 무게 · 길이를 숫자로 적는다"발 두 개 크기", "0.5~1초", "1미터 높이에서 떨어지는"처럼 적어야 손가락 버튼 소리가 나오지 않습니다.
  3. 빼 달라고 하지 말고 남길 것을 적는다"기계음 빼 줘"를 반복하자 매미 소리가 됐고, "경고음 없이"는 경고음으로 반영됐습니다.
  4. 결과가 멀어지면 수정을 쌓지 말고 앞선 후보로 돌아간다증기와 UI 소리 모두 결국 수정 전 후보를 썼습니다.
  5. 길게 뽑아 자르고, 음높이는 생성 밖에서 맞춘다명료한 구간만 잘라 쓰고, 계이름은 Unity pitch로 옮깁니다.
